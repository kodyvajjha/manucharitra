# Manucharitramu

Allasāni Peddana's *Svārociṣa-manusambhavamu* (*Manucharitramu*), in Telugu, with a phrase-by-phrase gloss (pratipadārtham), an English translation and notes on every padyam. Each verse can be read aloud line by line, and an optional Study layer adds metre marks and a fading-cue memory drill.

Site: https://kodyvajjha.github.io/manucharitra/

The page is plain static HTML. `index.html` loads one script per canto from `data/`.

Verses 5–7 of the first canto are Koundinya Vajjha's own translation.
